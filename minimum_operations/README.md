# Minimum Operations

Given a file containing a single `H` and an editor that can only do
**Copy All** and **Paste**, `minOperations(n)` returns the fewest operations
needed to get exactly `n` characters (or `0` if `n` is impossible).

The result is the sum of the prime factors of `n`.
